STATUS
MODEL = model's own probability of scoring anytime. MODEL ODDS = that probability expressed as fair American odds, for a quick side-by-side against BEST PRICE (the actual sportsbook line) — informational only, edge/EV are computed from the real probability, not this conversion. BOOK % = BEST PRICE converted back to an implied probability. RAW EDGE = MODEL minus BOOK % — the full model's disagreement with the market. IMP TOT = Vegas-implied point total for this player's team in this game, real market data set before kickoff, not a trailing stat. MU = opponent's position-specific TD-rate-allowed vs league average (real play-by-play, not points allowed) — 1.00 = league average, informational only, not yet a hard qualifier. STATUS: OFFICIAL clears every blueprint check (snap share, red-zone role, regression-risk, and edge/EV thresholds) — the fully disciplined plays. DEGEN means the model still shows real positive edge but something in that screen said no — real value, not a clean bet; hover for exactly why. No pill at all means neither: no real edge either way.

PROJ PTS = trailing L4-game average fantasy points (leakage-safe — never includes the game being predicted) times a matchup adjustment factor. DEF RANK = how many fantasy points the upcoming opponent has trailingly allowed to this position, ranked 1 (softest matchup) to 32 (toughest) among teams with enough games played. SNAP% = most recent game's offensive snap share. Baseline projection method, not yet validated against held-out data the way Track A/B are — see repo README. Early season weeks show blank/zero projections by design: the trailing average needs at least one PRIOR game to stay leakage-safe, so it can't project until each player has one game of history.
